# Problem-first Belle illustrations

Three concept illustrations introduce friction in literature-review work: finding the right full text, returning from a code to source evidence, and reconciling different review returns. They illustrate situations, not empirical outcomes or claims about another product.

Generated with the built-in image tool, then checked against the current Belle Black Comet canonical reference. Earlier failed generations remain outside this repository; the accepted full illustrations are preserved here. See [QA.json](QA.json).

The `layers` folder contains six transparent assets extracted with the image tool for the opening film. The renderer independently times their entrances, moves the two editorial feedback tokens from opposite sides, and draws connecting paths progressively. This is layered 2D animation; Belle's anatomy is not regenerated frame by frame. The white background is supplied by the composition. Source assets remain unchanged.

Typography, the simple A/B/Code feedback tokens, connecting lines, and circles are editorial graphics. They are not interface screenshots. The later Pilot segment uses unchanged authentic captures from `docs/demo/frames`.
