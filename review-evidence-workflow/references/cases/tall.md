## Project adapter

- Unit: original empirical study, reported in a peer-reviewed journal.
- Topic: cognitive/metacognitive support in technology-assisted L2/foreign-language
  learning; not restricted to AI.
- Eligibility: five project criteria; technology is a core learning component;
  the study's own data examine the relevant cognitive/metacognitive relationship.
- Evidence: core construct/extraction findings require methods/results/discussion
  evidence; a construct mentioned only in the introduction is insufficient.
- Appraisal: project-specific MMAT mapping. The historical implementation required
  Q2 and Q4 to be Yes for PASS; either No produced FAIL; uncertainty produced REVIEW.
  This gate belongs to TALL and is not presented as a general MMAT requirement.
- Extraction: design, participants, technology, constructs, cognitive and
  metacognitive affordances/challenges, with source-linked evidence.
- Human workflow: visible AI proposals, source PDF, field-level OK/Wrong and comments,
  exported reviewer returns, adjudication and updated records.

## Observed case: I031 correction and downstream state

I031 concerns learner-created digital flashcards and L2 self-regulation
(DOI `10.14742/ajet.10402`). The retained record contains:

| Field | Earlier state preserved in note | Current adjudicated state |
|---|---|---|
| Screening | Include | Include |
| MMAT Q2 | Yes | No |
| MMAT Q4 | Can't tell | No |
| Project MMAT gate | REVIEW | FAIL |

The appended adjudication note records the change on 2026-07-20. Earlier prose
still describes REVIEW, whereas structured fields record FAIL. The methodological
manuscript also reports the REVIEW-to-FAIL event. This is evidence of a recorded
human-authorized revision, not proof that an independent benchmark established
which appraisal judgment was objectively correct.

## What this teaches the reusable workflow

1. Eligibility and appraisal are separate states: screening Include did not imply
   permission to extract under this particular project's quality rule.
2. A human challenge can change item values and therefore a deterministic gate.
3. Preserve the earlier proposal and later decision, but resolve which version
   governs. Stale narrative notes must not override current authorized values.
4. Refresh any dependent extraction membership, counts, and claims after a change.

## What must not transfer

Do not transfer the L2 restriction, date range, five criteria, construct taxonomy,
exclusion codes, appraisal mapping, or Q2/Q4 gate into another review by default.
Do not report agreement with visible proposals as independent interrater reliability
or AI accuracy. The retrospective record does not establish comparative efficiency.
